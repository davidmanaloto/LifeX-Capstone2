## Prerequisites

- **Windows:** [Docker Desktop](https://www.docker.com/products/docker-desktop/)
- **Linux / macOS:** [Docker](https://docs.docker.com/get-docker/)

## Getting Started

1. Create and navigate to your project directory:
   ```bash
   mkdir <folder-name>
   cd <folder-name>
2. Clone repository:
   ```bash
   git clone <repository-url>

## Running Medplum

- **On a terminal**
1. Run container:
   ```bash
   docker compose up -d
2. Stop container:
   ```bash
   docker compose down
